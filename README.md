# security-lab

A hands-on application security and detection engineering lab, built in public
and still in progress. The goal is to practice the full loop: find a weakness,
reproduce it, fix it, measure the fix, detect it, and document it honestly.

Languages: English | [Bahasa Indonesia](README.id.md)

## Status

| Phase | Focus | Status |
|---|---|---|
| 0 | Repository and lab setup | Done |

| 2 | Honeypot and detection engineering | Not started |
| 3 | IoT security (optional) | Not started |

This table is updated as work is completed. Nothing is listed as done until it
has evidence in this repository.

## Scope and ethics

Only systems I own, or have written permission to test, are in scope. Read
[SECURITY.md](SECURITY.md) for the full rules on scope, data handling, and
disclosure.

## Method

Every result from an automated tool or an LLM is treated as a hypothesis and is
verified manually before it is recorded as a finding.

## Limitations

This is a learning project. It shows method and discipline, not professional
experience, and it does not replace a real security assessment.
